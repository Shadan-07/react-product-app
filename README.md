# React Product App

A product management application built with React and Vite.

## Features

* View products
* View product details
* Create products
* Edit products
* React Router navigation
* API integration with Axios

## Tech Stack

* React
* Vite
* React Router
* Axios
* Tailwind CSS
* React Context API

## Getting Started

Clone the repository:

git clone https://github.com/Shadan-07/react-product-app.git

Install dependencies:

npm install

Start the development server:

npm run dev

## Purpose

This project was created to practice React, routing, API integration, state management, and CRUD functionality.
